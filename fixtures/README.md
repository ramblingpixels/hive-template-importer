# Spectora test export

The final submission must include the candidate's real, shareable Spectora export in this directory.

Required workflow:

1. In Spectora, add a template such as **InterNACHI Residential**.
2. Choose **Export to spreadsheet → Export HTML Text**.
3. Confirm the workbook contains no customer information.
4. Place the workbook file here and update `NOTES.md` with its exact template name and source.

Spectora may name the file `.xls` even when the contents are a modern zipped Excel workbook. That is okay. True legacy binary `.xls` files are still unsupported.

The application currently uses a clearly labelled synthetic template for local seed data. It is not represented as a Spectora-generated file.
